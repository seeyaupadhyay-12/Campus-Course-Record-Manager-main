# Campus-Course-Record-Manager-main
Smart Student Manager is a Python-based desktop application designed to help students manage their academic activities, including student profiles, attendance, assignments, study planning, CGPA calculation, and college notices. Built using Python, Tkinter, and JSON for data storage  
## Features
### 1. Student Profile Management
Stores basic student details such as name, roll number, branch, semester, and college
Allows students to view and update their profile
### 2. Attendance Manageent
Records classes held and classes attended.
Automatically calculates attendance percentage.
Helps students monitor their attendance .
### 3. Assignment Manager
Add assignments with subject, title, and due date.
Displays all saved assignments.
Mark assignments as Pending or Completed.
Delete completed or unnecessary assignments.
### 4. Study Planner
Allows Student to create study tasks.
Stores task date, subject, priority and status.
Helps organize daily and academic study activities.
### 5. CGPA Calculator
Calculates CGPA using credit and grade-point values.
Supports multiple subjects
Uses a credit-weighted calculation.
### 6. College Notice Board 
Allows important college notices to be added and displayed.
Stores notice title, content, and date.
Allows old notices to be deleted.
### 7. Data Storage
Uses JSON files to store student information and module data.
Data remains available after closing and reopening the application.
### 8. User-Friendly GUI
Built using Python Tkinter.
Provides buttons and separate windows for different modules.
Designed to be simple for students to use.
### 9. Input Validation
Checks for empty fields.
Validates numerical values such as attendance and grade points.
Displays warning messages when incorrect data is entered.
### 10. Modular Design
Each major function is organized into separate Python functions.
Makes the program easier to understand, test, maintain, and extend.
